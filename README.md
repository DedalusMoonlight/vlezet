# Влезет. Покажем, как

**Спланируйте загрузку машины до того, как начнёте носить коробки.**

«Влезет» помогает подготовить переезд, доставку или рейс малого бизнеса. Укажите размеры кузова, добавьте коробки и порядок остановок — получите раскладку и пошаговую 3D-инструкцию загрузки и выгрузки.

## Что умеет приложение

- **Выбирать транспорт.** Фургоны и минивэны LADA, Volkswagen, Renault и Ford с указанием версии и источников размеров. [Каталог](docs/vehicles.md).
- **Подбирать раскладку.** Учитывает размеры кузова, грузоподъёмность, размеры и массу коробок.
- **Учитывать особенности груза.** Выбирайте разрешённые грани, ограничивайте массу сверху и отмечайте обязательные коробки.
- **Планировать несколько остановок.** Задавайте очередность выгрузки, чтобы нужный груз оставался доступным.
- **Предлагать другой порядок выгрузки.** Если весь груз не разместился, приложение проверит другие порядки остановок и предложит найденный вариант для всех коробок.
- **Показывать каждый шаг в 3D.** Вращайте сцену, просматривайте загрузку и выгрузку, корректируйте положение коробок вручную с проверкой ограничений.
- **Загружать списки из таблиц.** Импортируйте Excel и CSV с сопоставлением колонок и предпросмотром.
- **Сохранять и передавать результат.** Автосохранение на устройстве, перенос проектов в JSON и PDF-инструкция с изображениями шагов.

Расчёт выполняется на вашем устройстве, без регистрации. Android-приложение работает без интернета. Веб-версию можно установить на главный экран как PWA; после первого открытия по HTTPS она также доступна офлайн.

## Скачать для Android

1. Откройте [страницу релизов](https://github.com/DedalusMoonlight/vlezet/releases) и выберите версию.
2. Скачайте **`vlezet-<версия>-android.apk`** в разделе Assets.
3. Откройте файл на телефоне и разрешите установку из выбранного браузера или файлового менеджера.

Нужен **Android 8 или новее** с актуальным Android System WebView. Перед обновлением сохраните проект в JSON: установка новой версии может потребовать удаления предыдущей. [Подробная инструкция](docs/android.md).

## Первый план за несколько минут

1. Выберите автомобиль из каталога или введите полезные размеры кузова и грузоподъёмность.
2. Добавьте коробки вручную или импортируйте таблицу.
3. При необходимости задайте остановки, разрешённые грани и ограничения на укладку сверху.
4. Запустите расчёт и осмотрите раскладку в 3D.
5. Следуйте пошаговой инструкции или сохраните её в PDF.

Для знакомства используйте демонстрационный проект. Подробнее о настройках, импорте и обмене — в [руководстве пользователя](docs/guide.md).

Кузов и грузы представлены прямоугольными объёмами. Подтвердите реальные полезные размеры, учитывая арки и дверной проём. Приложение помогает спланировать размещение; крепление груза и допустимые нагрузки на оси нужно проверять отдельно.

## Запустить веб-версию

Установите Git и **Node.js 24**, затем выполните:

```sh
git clone https://github.com/DedalusMoonlight/vlezet.git
cd vlezet
npm ci
npm run dev
```

Откройте [localhost:5173](http://localhost:5173). Для обмена планами по ссылке запустите во втором терминале из той же папки `npm run dev:api`. Ввод грузов, расчёт, 3D и экспорт работают без API.

Команда `npm run build` создаёт веб-приложение в папке `dist`. [Инструкция по размещению](docs/running.md) описывает HTTPS, сервер обмена, хранение данных и обновления. [Команды для разработчиков](docs/development.md).
