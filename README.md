# Влезет. Покажем, как

PWA для планирования загрузки машины: прямоугольный кузов, коробки и остановки → проверенная раскладка и пошаговая 3D-инструкция. Работает на устройстве, без регистрации, офлайн после первого открытия.

## Быстрый старт

Node.js 24 LTS:

```sh
npm ci
npm run dev
```

Для ссылок на снимки во втором терминале: `npm run dev:api`. Основной расчёт работает без сервера.

Production PWA: `npm run build`, затем `npm run preview`. Сервис-воркер требует HTTPS либо localhost. Внешний хостинг пока не опубликован.

## Что есть в P0

- Ручной ввод и XLSX/XLS/CSV с предпросмотром, единицами и проверками.
- Шесть физических граней, обязательные грузы, лимит массы сверху (в том числе 0), остановки.
- Локальный отменяемый поиск в worker; несколько опор, передача нагрузки, проверенный порядок выгрузки.
- Интерактивная 3D-сцена, проверяемые ручные правки, undo/redo, анимированные шаги.
- Автосохранение, JSON-копии, PDF с кириллицей и кадрами шагов.
- Неизменяемые снимки на 30 дней, отдельный секрет удаления, Fastify/SQLite API.

Поиск эвристический: лучший найденный вариант, без гарантии глобального оптимума. Прочность, крепление, динамика и нагрузки на оси не рассчитываются. Подтвердите полезные размеры кузова и доступную грузоподъёмность.
