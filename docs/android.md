# Android APK

Основной способ проверки на Android — устанавливаемый APK из [GitHub Releases](https://github.com/DedalusMoonlight/vlezet/releases). Mac, общий Wi-Fi и опубликованный сайт для работы не нужны: интерфейс, расчёт, worker, каталог и шрифты находятся внутри приложения.

## Скачать и установить

Историческая приёмка первой сборки 0.1.3: [результаты проверки](android-acceptance.md). Для установки выбирайте свежую версию в Releases.

1. Открыть [Releases](https://github.com/DedalusMoonlight/vlezet/releases) и выбрать версию.
2. Нажать «Скачать APK для Android» или выбрать `vlezet-<версия>-android.apk` в Assets.
3. Открыть APK на телефоне. При запросе Android разрешить установку этому браузеру/файловому менеджеру. Распаковка ZIP не нужна.
4. Запустить «Влезет». Для первой загрузки демо и расчёта интернет не требуется.

APK рассчитан на Android 8+ с актуальным Android System WebView. Это тестовая debug-сборка, не публикация в Google Play. После успешной Android-проверки в `main` CI публикует отдельный preview-релиз `v0.1.<номер сборки>` с APK, SHA256SUMS, сведениями о версии, manifest, сертификате и скриншотом. В отличие от временных Actions artifacts, файлы релиза не истекают через 30 дней. Сборки других веток остаются в Actions artifacts.

## Возможности и ограничения

- Ввод, Excel/CSV/JSON, расчёт и 3D работают локально. Проекты сохраняются в данных приложения; браузерные проекты автоматически не переносятся — используйте JSON.
- PDF/JSON/шаблон XLSX передаются в системное меню «Сохранить или отправить». Выберите подходящее приложение/хранилище; доступ ко всем файлам не запрашивается. Временные экспортные копии находятся в кеше приложения.
- Обмен по ссылке пока не подключён к опубликованному серверу. Обмен готовым проектом возможен через JSON.
- Debug-ключ создаётся заново на runner и не сохраняется в публичном кеше. Для перехода между preview-сборками **сначала сохраните JSON-копию**, затем при несовместимой подписи удалите прежнее приложение и установите новое. Удаление приложения удаляет локальные проекты. Первая приватная сборка использовала кеш ключа; этот кеш удаляется перед публичным релизом.
- Для долгосрочного распространения потребуется отдельная release-подпись в GitHub Secrets; она намеренно не подменяется тестовым ключом. Ключи не входят в репозиторий или артефакты.

## Разработка

Node 24, JDK 21, Android SDK 36, SDK licenses согласно стандартной установке Android Studio. Подготовка:

```sh
npm ci
npm run android:sync
cd android
./gradlew :app:assembleDebug --no-daemon --max-workers=2
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Нативные ресурсы лежат в `android/`, web build отдельно в `dist-android/`; сервис-воркер в APK не регистрируется. Не добавляйте `server.url`: приложение должно открывать bundled assets. `app.vlezet.preview` — идентификатор тестовой установки. Версия CI: `0.1.<GITHUB_RUN_NUMBER>`.

CI проверяет подпись через apksigner, включает 3D/расчёт/восстановление в Android 15 emulator с отключёнными Wi-Fi и mobile data. Полный физический телефонный прогон (файловый менеджер, экспорт в выбранные приложения, жесты, память, системное восстановление) пока не выполнен.

Основа упаковки — [Capacitor Android](https://capacitorjs.com/docs/android), экспорт — [Filesystem](https://capacitorjs.com/docs/apis/filesystem) и [Share](https://capacitorjs.com/docs/apis/share).
