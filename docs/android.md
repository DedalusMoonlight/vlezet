# Влезет для Android

Планируйте загрузку, просматривайте коробки в 3D и следуйте инструкции прямо с телефона. Расчёт и сохранённые проекты доступны без интернета и регистрации.

## Установка

Требования: **Android 8 или новее**, актуальный Android System WebView.

1. Откройте [релизы Влезет](https://github.com/DedalusMoonlight/vlezet/releases) на телефоне.
2. Выберите версию и скачайте файл `vlezet-<версия>-android.apk` из раздела Assets. Архивы исходного кода для установки не нужны.
3. Откройте скачанный APK. Если Android запросит разрешение, разрешите установку приложений из выбранного браузера или файлового менеджера.
4. Запустите «Влезет» и откройте демонстрационный проект либо добавьте свой автомобиль и грузы.

## Проекты и обмен

Изменения автоматически сохраняются на устройстве. Для резервной копии или переноса на другой телефон экспортируйте проект в **JSON**, затем откройте его в приложении на другом устройстве. Для передачи готовой инструкции используйте **PDF** с изображениями шагов загрузки.

Экспорт открывает системное меню: можно сохранить файл или передать его через доступное приложение. Данные браузерной версии и Android-приложения хранятся отдельно — переносите их через JSON. Обмен по веб-ссылке доступен в веб-версии с подключённым сервером обмена.

## Обновление

1. Сохраните важные проекты в JSON вне приложения.
2. Скачайте APK нужной версии со страницы релизов и откройте его.
3. Если Android не позволяет установить его поверх предыдущей версии, удалите старое приложение и установите новое.
4. Откройте сохранённый JSON, чтобы восстановить проект.

Удаление приложения или очистка его данных удаляет локальные проекты. Храните резервные копии отдельно.

## Если что-то не получается

- **Android запрещает установку:** разрешите установку из того приложения, которым открываете APK.
- **Не устанавливается поверх старой версии:** сохраните JSON-копию и выполните переустановку по инструкции выше.
- **Не отображается 3D:** обновите Android System WebView и перезапустите приложение.
- **Не получается передать файл:** выберите другой получатель в системном меню или сохраните файл на устройство.

Об ошибке можно сообщить в [Issues](https://github.com/DedalusMoonlight/vlezet/issues). Укажите версию приложения, модель телефона, версию Android и действия, после которых возникла проблема. Не прикладывайте конфиденциальные грузы или документы.
