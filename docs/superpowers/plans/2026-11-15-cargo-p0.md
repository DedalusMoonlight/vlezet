# План реализации планировщика загрузки P0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Метод исполнения пока не выбран; рекомендация — последовательное выполнение основным агентом.

**Goal:** Создать PWA, в которой можно подготовить груз, рассчитать загрузку прямоугольного кузова с несколькими опорами и пройти проверенную 3D-инструкцию на телефоне.

**Architecture:** Интерфейс и расчёт выполняются на устройстве. Решатель работает в worker, независимый валидатор проверяет размещение и шаги. Небольшой сервер хранит только опубликованные снимки.

**Tech Stack:** TypeScript, React 19, Vite, Three.js, React Three Fiber 9, Drei, Zustand, Radix UI, CSS Modules, Zod, Dexie, SheetJS CE, pdf-lib, Fastify, SQLite, Vitest, fast-check, Playwright; Node.js 24 LTS и npm workspaces.

**Spec:** [ТЗ редакции 2](../../../outputs/cargo-p0-spec.md). Каноническая локальная копия: /Users/ttahil/Documents/Codex/2026-10-21/new-chat-3/outputs/cargo-p0-spec.md. [Страница ТЗ](https://chatgpt.com/space/page_17dd87fed43c8191a26c6e49d0a6cfad).

## Global Constraints

- Одна машина, один рейс, загрузка всех вещей в начале маршрута, последовательная выгрузка на заданных остановках.
- В расчёте — целые миллиметры и граммы. Доли передаваемой нагрузки сохраняются без округления на каждом уровне.
- Все предметы — жёсткие прямоугольные параллелепипеды, расположенные параллельно осям кузова.
- Зазоры по умолчанию: границы и потолок 10 мм, между коробками по горизонтали 5 мм, контакт с полом/опорой 0 мм.
- Модель support-v1: контакт не менее 95% дна; четыре угла в фактической области опоры; покрытие объединением контактов, расширенных на g/2, где g = min(горизонтальный зазор проекта, 5 мм). При g = 0 требуется 100% фактического покрытия.
- Нагрузка распределяется по фактической площади контакта. Это приближение, не механический расчёт устойчивости.
- Все грузы обязательны, все грани разрешены и масса сверху без ограничения по умолчанию. Значение 0 кг запрещает ставить сверху груз.
- Предел входа — 300 коробок, 100 типов, 20 остановок. XLSX/XLS/CSV до 10 МиБ, предпросмотр до 1000 непустых строк.
- Бюджет быстрого расчёта по умолчанию 5 секунд; пользователь может продолжить поиск до 30 секунд.
- Самостоятельно не расширять P0 аккаунтами, AI-вводом, несколькими машинами, осевыми нагрузками или произвольными поворотами.
- Все подписи пользователю на русском. «Лучший найденный вариант» вместо обещания математического оптимума; ошибка поиска отличается от доказанной невозможности.
- Ссылки хранят снимки до 30 дней; снимок не больше 1 МиБ. Публикация внешнего сервиса и выбор платного тарифа — отдельный шаг после готовой сборки.

## Review Focus

- Разделение нагрузки между двумя опорами и повторное объединение на нижней коробке: масса сохраняется, не удваивается. Проверка в задаче 3.
- Узкая щель против широкого провала с одинаковым процентом опоры: нельзя оценивать опору только процентом площади. Проверка в задаче 3.
- Изменение входных данных и запоздалое сообщение worker: старый результат не заменяет текущий. Проверка в задаче 6.
- Формулы Excel, десятичная запятая и неизвестные единицы: не превращаются в молчаливо неверные размеры. Проверка в задаче 8.
- Удаление данных браузера, квота хранения и обновление PWA: нет ложного статуса «сохранено» и потери последнего экспорта. Проверка в задаче 11.
