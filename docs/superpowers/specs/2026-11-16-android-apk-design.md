# Android APK

Запрос: пользователь хочет скачивать Android-приложение как артефакт приватного GitHub и устанавливать на телефон. Wi-Fi-просмотр и установка PWA больше не являются основным способом передачи Android-версии.

Решение исполнителя: Capacitor 8 с локально упакованной текущей React/Vite сборкой, appId `app.vlezet.preview`, название «Влезет». Альтернативы: полная перепись на Kotlin слишком велика для текущей задачи; TWA требует опубликованный HTTPS-сайт, которого пока нет. Интерфейс, worker, шрифты и файлы включаются в APK, серверный URL не прописывается.

Первая поставка — подписанный debug APK для тестирования, не Google Play release. Debug keystore кешируется в Actions; при потере кеша подпись изменится, поэтому перед переустановкой нужно сохранить JSON. Production signing и его секреты не создаются в этой задаче. Версия APK содержит номер CI-запуска. Репозиторий и артефакт остаются приватными.

В Android не регистрируется service worker и не показывается предложение установить PWA. PDF/JSON/XLSX экспорт использует официальный Filesystem + Share, ошибки показываются в интерфейсе. Файлы помещаются во временный кеш, системное меню позволяет отправить их выбранному приложению. Импорт остаётся через системный выбор файла WebView. Ссылки на снимки не создаются без развёрнутого сервиса; соответствующая кнопка объясняет ограничение и предлагает обмен JSON.

Важные пределы: Android System WebView должен быть современным; min SDK 26. Браузерная версия сохраняется. Native-сборка не содержит сервис-воркер, не зависит от Mac или dev server, не запрашивает доступ ко всем файлам. Поддерживаются системные отступы экрана.

Приёмка: локальные typecheck/lint/unit/browser checks; CI собирает debug APK, проверяет подпись и manifest, прикладывает APK, SHA256 и сведения о сборке на 30 дней. Android emulator smoke test запускает приложение, рассчитывает план без сети и проверяет отсутствие crash. На физическом телефоне проверка остаётся пользователю.
