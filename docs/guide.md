# Как пользоваться Влезет

## 1. Выберите автомобиль

Выберите вариант из каталога или задайте размеры вручную. Указывайте полезное прямоугольное пространство: длину, ширину и высоту, в пределах которых действительно можно разместить груз. Учитывайте колёсные арки, перегородку и дверной проём.

Проверьте размеры выбранной модели по своей машине. Грузоподъёмность — доступная масса груза, а не полная разрешённая масса автомобиля.

## 2. Добавьте груз

Для каждой позиции задайте название, размеры коробки, массу и количество. В одном проекте можно рассчитывать до 300 экземпляров коробок.

Дополнительные настройки:

- **Остановка:** меньший номер означает более раннюю выгрузку.
- **Обязательный груз:** отметьте коробки, которые должны попасть в план.
- **Разрешённые грани:** по умолчанию коробку можно переворачивать. Если это недопустимо, выберите на интерактивной модели те грани, на которых она может стоять.
- **Максимальная масса сверху:** оставьте без ограничения или укажите допустимую массу. Значение `0` запрещает ставить другой груз сверху.

### Импорт из таблицы

Поддерживаются **XLSX, XLS и CSV**. Выберите файл, сопоставьте его колонки с полями груза, укажите единицы измерения и проверьте предпросмотр. Исправьте отмеченные ошибки перед импортом. Если таблица использует формулы, сохраните для импорта копию с рассчитанными значениями.

## 3. Рассчитайте и проверьте план

Запустите расчёт. Приложение ищет раскладку с учётом выбранных ограничений, опоры коробок и порядка выгрузки. Коробка может опираться на несколько нижних коробок; нагрузка учитывается для каждой опоры.

Осмотрите результат в 3D: вращайте сцену, выбирайте коробки и проверяйте список размещённого груза. При ручном изменении положения и ориентации приложение проверяет ограничения. Неудачную правку можно отменить.

Если часть груза не размещена или план не найден, проверьте размеры, массу и ограничения. Можно продолжить поиск, изменить условия или выбрать другой кузов. Отсутствие найденного плана не доказывает, что подходящей раскладки не существует.

## 4. Следуйте инструкции

Откройте пошаговый просмотр загрузки и переходите между шагами в 3D. Для доставки используйте последовательность выгрузки по остановкам. Сохраните **PDF**, чтобы передать инструкцию вместе с изображениями шагов.

Расчёт описывает прямоугольные грузы и пространство кузова. Он не заменяет проверку прочности упаковки, крепления, нагрузок на оси и безопасной перевозки.

## 5. Сохраните или передайте проект

Проект автоматически сохраняется на текущем устройстве. Экспортируйте **JSON** для резервной копии или дальнейшего редактирования на другом устройстве. Очистка данных приложения или браузера удаляет локальное сохранение.

В веб-версии с сервером обмена можно создать ссылку на план. Это отдельная неизменяемая копия: последующие правки исходного проекта в неё не попадут. Ссылка действует **30 дней**; открыть её может любой, у кого она есть. Не публикуйте конфиденциальные данные.

Для досрочного удаления опубликованного плана сохраните отдельную копию секрета удаления. Обычный JSON проекта и PDF этот секрет не содержат.
