# Итоговое ревью P0

Проверен исходный диапазон `6dbb955..1667451` независимым агентом; вердикт **With fixes**. Ревью было прервано вместе с чатом и затем продолжено тем же агентом. Повторное ревью исправлений не выполнялось: они проверяются воспроизводящими тестами и общим набором проверок.

## Важные замечания и исправления

1. XLSX доверял central-directory размеру, а SheetJS выделял память по local header. Теперь заголовки сверяются, фактическая распаковка ограничена; перед SheetJS архив пересобирается из проверенных данных без исходных extra fields. Тесты ложного local размера и ложных размеров в обоих заголовках прошли RED → GREEN. Проверяется обычный XLSX и потоковый ZIP с data descriptors.
2. После изменения груза пропадал доступ к удалению опубликованного снимка. Управление снимками доступно всегда; только создание новой ссылки требует готового результата. Браузерный тест публикация → изменение груза → удаление прошёл RED → GREEN.
3. Обновление PWA могло потерять черновик машины/позиции и опередить запись IndexedDB. Теперь оно блокируется при незавершённых/невалидных правках, диалоге, расчёте, экспорте и до успешного автосохранения. Проверки маркеров редакторов прошли RED → GREEN; отдельно проверяется политика обновления.
4. JSON/IndexedDB теряли доказательство невозможности, пустой неудачный поиск и отмену. Простые доказательства размера/массы/объёма теперь вычисляются повторно из входных данных; присланным status/issues по-прежнему нет доверия. Отмена хранится отдельно от наличия результата, включая отмену до первой найденной раскладки. Roundtrip и IndexedDB tests прошли RED → GREEN; E2E проверяет отмену после перезапуска.
5. В финальной проверке TypeScript обнаружена ненаруженная ранее nullable-ветка в тесте shelf seed. Добавлена явная проверка null перед вызовом валидатора. Рабочий алгоритм не изменён.

## Отложенное небольшое замечание

Черновик ручной позиции может остаться после внешней замены результата решателем. История правок сбрасывается, независимый валидатор не позволяет применить недопустимую раскладку. До улучшения интерфейса после пересчёта нужно заново выбрать коробку перед ручной правкой. Исправление привязки черновика к ревизии результата отложено как небольшое замечание ревью.

## Решения и пределы проверки

- Работа выполнялась в отдельном новом Git-репозитории и feature-ветке; дополнительный worktree не нужен. Основная ветка сохранена, слияние не выполнялось.
- Используется локальный Node 24 и кеш проекта; глобальный Node 26 не менялся.
- Заголовки задач плана нормализованы для скриптов исполнения, требования сохранены. Временный перенос браузерных проверок из-за загрузки движков закрыт полным прогоном.
- API применяет независимый геометрический валидатор, а не только проверку JSON-схемы. Внутренние кандидаты проверяются быстрым валидатором, опубликованные результаты — полным. Идентификатор `floor` зарезервирован для опоры на пол.
- Каталог содержит проверенные размеры; грузоподъёмность конкретной комплектации пользователь подтверждает по документам. Неизвестные значения не выдумываются.
- Метки 3D рисуются локальными canvas-текстурами, без внешних шрифтов и HTML-порталов; это устраняет офлайн-зависимость.
- Перед EP-поиском строится проверяемая раскладка рядами/стопками. Это эвристика: полнота и глобальная оптимальность не заявляются. Измерения относятся к фиксированным синтетическим задачам, результат на произвольных грузах может отличаться.
- Физические iPhone/Android не подключены. Их установка, восстановление, touch, WebGL и производительность остаются непроверенными; эмуляция на Mac не выдаётся за реальное устройство.
- Внешние HTTPS-хостинг, reverse proxy и Docker deployment не запускались. Локальный сервис и подготовленный Dockerfile не доказывают готовность эксплуатации.
- Динамическая устойчивость, крепление груза, нагрузки на оси и возможность ручного подъёма исключены из согласованной модели P0. Распределение массы по площади контакта — приближение.
- Production audit не обнаружил известных уязвимостей. 12 low/moderate предупреждений dev-цепочек зафиксированы; принудительное понижение инструментов через audit fix --force не выполнялось.

Итоговые количества тестов и доказательства — в `acceptance.md`.
