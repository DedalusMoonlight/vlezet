# Проверки P0 (2026-11-15)

Проверено локально на macOS arm64 с Node 24.22.3. Это программная приёмка и браузерная эмуляция; реальные телефоны не подключены. Внешний сервис не опубликован.

- TypeScript, ESLint, 55 модульных тестов и production build прошли перед итоговым ревью.
- 27 сквозных проверок production PWA прошли: Chromium, Pixel 7 viewport, WebKit/iPhone 13 viewport. Включены импорт, грани, редактирование, отмена 300 коробок, 3D-инструкции, офлайн-перезапуск, JSON/PDF и удаление снимка. После дополнительных исправлений итоговые результаты фиксируются ниже.
- PDF проверен текстовым извлечением (pypdf) и отрисовкой (Poppler). Статический Noto Sans обеспечивает корректную кириллицу; переменный шрифт был заменён после обнаруженного дефекта отображения. Лицензия лежит рядом со шрифтом.
- Production dependency audit: 0 известных уязвимостей. Полный audit: 12 low/moderate в dev-цепочках glob/minimatch/deepmerge; high/critical нет. Они используются инструментами сборки/линтинга с локальными статическими шаблонами. Автоматический `audit fix --force` предлагает понижение основных инструментов; оно не выполнялось.

## Производительность

Набор v1: 20 заранее зафиксированных разрешимых задач, по 100 коробок / 20 типов / 5 остановок. Для каждой сохранено независимо проверенное размещение-свидетельство. 8 задач на полу, 8 вертикальными колоннами, 4 со смешанными рядами. Это синтетические повторяющиеся грузы, а не доказательство эффективности на произвольном бизнес-грузе. Набор не изменялся после первого замера.

| Среда на том же Mac | Полный план до 5 с | Время до готового экрана | Кадры при вращении 100 коробок |
| --- | --- | --- | --- |
| Chromium desktop | 20/20 | 133–245 мс | 60,2 FPS |
| Chromium / Pixel 7 viewport | 20/20 | 230–255 мс | 60,2 FPS |
| WebKit / iPhone 13 viewport | 20/20 | 217–303 мс | 60,3 FPS |

`docs/benchmark-before.json`: исходный EP-поиск 1/20. `docs/benchmark-after.json`: с независимой проверкой нового начального варианта рядов/стопок 20/20. Браузерные сырые замеры: `docs/browser-performance-*.json`. Измерение FPS — частота requestAnimationFrame во время вращения сцены в headless браузере, не физический дисплей телефона. Для воспроизведения: `npm exec tsx scripts/benchmark.ts`; браузеры: `PW_PREVIEW=1 PW_BENCH=1 npm run test:e2e` после build.

## Что ещё проверить на устройствах

На реальном iPhone/Safari и Android/Chrome: установка с HTTPS, клавиатура и выбор файлов, жесты 3D, фоновое восстановление, потеря/восстановление WebGL, офлайн после закрытия браузера, открытие/сохранение PDF, фактический FPS и время 100/300 коробок. Модели устройств и версии ОС пока не зафиксированы. Эмуляция эти пункты не заменяет.

Dockerfile и CI подготовлены. Docker на этом Mac не собирался; результат удалённого GitHub Actions нельзя считать зелёным без проверки его выполнения. HTTPS hosting и публикация API — отдельное действие.
