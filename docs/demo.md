# Демонстрация «Влезет. Покажем, как»

1. Открыть production PWA, дождаться «Доступно офлайн». Исходный демопроект содержит 18 коробок и три остановки. На телефоне установить через меню браузера.
2. Показать редактирование хрупкого груза: только -Z снизу, 0 кг сверху, обязательность галочкой. Выбрать физические грани в 3D и теми же шестью кнопками.
3. Скачать шаблон XLSX, заполнить (или использовать CSV `fixtures/import/decimal.csv`). Импортировать через предпросмотр и явные единицы. Продемонстрировать отказ формуле в `fixtures/import/mixed.xlsx`.
4. Рассчитать загрузку. Показать процент объёма, массу, цвет и номер остановки. Выбрать коробку и попытаться вывести её за кузов: кнопка применения заблокирована с объяснением.
5. Перейти в 3D-инструкцию: загрузка, движение очередной коробки через двери, выгрузка по остановкам, отметка обработанного груза. Перезагрузить приложение: шаг и отметка сохраняются.
6. Отключить сеть. Пересчитать, открыть инструкцию, скачать JSON и PDF; текст PDF остаётся кириллическим, обзор — реальная раскладка.
7. С доступным локальным API создать ссылку. Открыть на другом клиенте: отдельный неизменяемый снимок, возможность скопировать в свой проект. Удалить снимок автором; получатель видит понятное сообщение. Для другого физического телефона потребуется отдельно настроенный HTTPS origin.
8. Для демонстрации нескольких опор открыть `fixtures/demo/multiple-supports.vlezet.json`: большая обязательная коробка опирается на две маленькие; снятие любой опоры раньше верхней запрещено. В инструкции верхняя выгружается первой.
9. Честный отказ: задать обязательной коробке длину, ширину и высоту больше полезного кузова. Сообщение говорит о доказанном несоответствии размеров. Для неудачи эвристики формулировка другая: часть груза не размещена, можно продолжить поиск.

Не обещать математический оптимум, расчёт устойчивости и безопасности крепления, учёт осевых нагрузок или точную геометрию реальной машины. Основной эффект: понятная раскладка с остановками, проверенными опорами и инструкцией, доступная малому бизнесу без аккаунта.
