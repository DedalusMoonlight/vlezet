## Принятые решения и последствия

1. Capacitor с локальным bundle сохраняет существующую кодовую базу и офлайн-расчёт. Цена: UI и 3D зависят от Android System WebView; это не нативный Compose-интерфейс.
2. Debug APK из приватных GitHub artifacts — тестовое распространение. Ключ кешируется в CI; потеря кеша может потребовать JSON-копию, удаление прежней установки и повторную установку. Долгосрочная release-подпись — отдельная задача.
3. Публичный сервер снимков не развёрнут, поэтому публикация ссылки в Android отключена; обмен через JSON доступен. До подключения сервера публичных ссылок нет.
4. Android SDK/JDK/эмулятор используются на GitHub runner. Глобальная среда Mac не менялась. Реальный телефон необходимо проверить отдельно; возможны особенности системного выбора файлов, экспорта и восстановления процесса.
5. Gradle-команды ограничены `:app:`. Первая CI-сборка запускала также instrumentation-сборки upstream Cordova library и упала на конфликте Kotlin в её тестовом APK. Зависимости приложения продолжают собираться, проверяется наш интеграционный тест; сторонние тестовые приложения в acceptance не входят.

CI сообщает о deprecated action-версиях и миграции `ubuntu-latest`. Они не помешали этой сборке; обновление инфраструктурных action-версий оставлено отдельной задачей.
