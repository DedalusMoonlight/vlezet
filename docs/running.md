# Запуск

Node.js 24 LTS, npm. `npm ci`, затем `npm run dev`. Интерфейс: http://127.0.0.1:5173.

В этой рабочей копии есть изолированный Node 24 в `.tooling/node_modules/node/bin`; он не хранится в Git. Локально команды можно запускать с `PATH="$PWD/.tooling/node_modules/node/bin:$PATH"`.

`npm run build` создаёт `dist/`. `npm run preview` открывает production-сборку на http://127.0.0.1:4173. Service worker и установка доступны на localhost либо HTTPS, но не по обычному HTTP-адресу в локальной сети. Для телефона понадобится HTTPS-хостинг или локальный HTTPS-туннель, который пользователь выберет отдельно.

`npm test`, `npm run typecheck`, `npm run lint` — проверки кода. Для браузеров: `npx playwright install chromium webkit`, затем `npm run test:e2e`. Полная офлайн-проверка: `npm run build`, затем `PW_PREVIEW=1 npm run test:e2e`. Если `PLAYWRIGHT_BROWSERS_PATH` задавался при установке, используйте тот же путь при запуске.

# Сервер снимков

В отдельном терминале: `npm run dev:api`. Vite проксирует `/api` на 127.0.0.1:3001. Основное приложение работает без сервера; публикация ссылки требует доступного API. Файл `.env.example` описывает настройки; сам файл .env автоматически не читается. Передайте переменные процессу или используйте Node `--env-file`.

Для внешнего размещения нужен один origin HTTPS: статические файлы из `dist/`, SPA fallback на `index.html` для `/s/*`, прокси `/api/*` на Fastify. Не проксируйте `/api` в SPA fallback. Выбор хостинга и внешняя публикация ещё не выполнялись.

SQLite должен находиться на постоянном диске. Docker: `docker build -f apps/share-api/Dockerfile -t vlezet-api .`; запустить с volume, принадлежащим UID 1000, в `/data`. Сервис работает от пользователя node. Dockerfile подготовлен; локальная Docker-сборка не является частью проверок на Mac.

`TRUST_PROXY=true` включайте только за доверенным reverse proxy, который перезаписывает forwarded headers, а порт API закрыт извне. Иначе IP-лимит можно подменить. По умолчанию доверие прокси выключено. Публикации: 10/час/IP, тело до 1 МиБ. В приложении и API нет access logs с URL-токенами. На reverse proxy также отключите/редактируйте журнал URL `/s/*` и `/api/snapshots/*`.

Снимок неизменяем, истекает через 30 дней; срок проверяется при GET, очистка выполняется ежедневно. Секрет удаления хранится в IndexedDB автора отдельно от проекта; можно скачать отдельную секретную копию. В серверной БД хранится SHA-256 секрета. После очистки браузера восстановить авторство можно только с сохранённым секретом (DELETE `/api/snapshots/TOKEN`, Authorization: Bearer SECRET). Секрет не включается в JSON проекта, PDF или общедоступный снимок.

Резервное копирование: используйте SQLite Online Backup API (`better-sqlite3` method `backup`) либо остановите API и скопируйте SQLite вместе с WAL/SHM, если они остались. Не копируйте только основной файл при активном WAL. Храните резервные копии приватно: они содержат опубликованные грузы. Проверьте восстановление на копии БД перед эксплуатацией.

Для смены базы/обновления завершайте процесс через SIGTERM: подключение SQLite закрывается. При запуске выполняется очистка просроченных строк.

# Данные и ограничения

Размеры в интерфейсе вводятся в мм/см/м, массы в г/кг; внутри целые мм и г. Исходные метки: +Z верх, -Z низ, +X перед, -X зад, +Y справа, -Y слева. X кузова направлен от задних дверей в глубину, Y слева направо, Z вверх. Разрешённая грань — та, на которой коробка может стоять.

Каталог — пять проверенных вариантов Ford; источники и дата в `apps/web/src/data/vehicles.json`. Это стартовые размеры, которые пользователь подтверждает по своей машине. Длина учитывает выступ перегородки, где такая величина опубликована; ширина между арками, высота ограничена задним проёмом. Грузоподъёмность подтверждается отдельно; полная масса авто ею не является.

Модель support-v1 проверяет реальные контакты нескольких опор, 95% покрытия, четыре угла и отсутствие широких провалов. Нагрузки распределяются пропорционально реальной площади. Крепление, деформация, динамика и осевые нагрузки не рассчитываются. Поиск эвристический: «не найдено» не означает доказанную невозможность.

JSON — переносимая независимая копия, без секретов публикации. IndexedDB может быть удалён системой или пользователем; сохраняйте JSON важных проектов. PWA кеширует код, worker, импортёр, PDF-библиотеку и лицензированный кириллический шрифт. Снимки с сервера в офлайн-кеш не попадают.
